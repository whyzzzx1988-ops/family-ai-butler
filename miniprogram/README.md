# 全家管家 · 微信小程序（第五周 A2）

原生小程序（无构建链），对接本仓库后端 API。三页闭环：简报 / 说一句 / 学习，外加登录页。

## 打开方式

1. 微信开发者工具 → 导入项目 → 选本目录 `miniprogram/`
2. AppID：先用测试号或你自己的小程序 AppID（改 `project.config.json` 的 appid；后端微信登录需要与之配套的 AppID/Secret）
3. 详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
4. 后端先在本机跑起来（见仓库根 README，默认 http://127.0.0.1:8080）

## 环境约定

- 后端地址与订阅模板 ID 在 `utils/config.js`：模拟器用 127.0.0.1，真机改局域网 IP，正式版改已备案 HTTPS 域名并在公众平台配置服务器域名
- 后端微信登录需要环境变量 `WECHAT_APPID` / `WECHAT_SECRET`（见根 README「微信登录与订阅消息自检」），未配时小程序登录会收到 503 明示

## 主题

v1.3 起换「深空巡星」主题（参考宇宙单词类应用的深空视觉语言）：深空底 + 星尘、熔金主色、宇宙面板卡、胶囊按钮。
设计令牌与四页映射见项目《小程序宇宙主题设计规划-v1.md》。v2 增加展示层三件：TabBar 星尘图标
（assets/icons，行星/气泡/星芒）、学习页「成就星瓶」（星点数 = 学习记录数，纯展示）、简报页轨道装饰
（CSS 轨道环缓旋）。三件均为展示层，不改变任何接口与业务口径。

## 登录流程

wx.login 的 code 换后端 token（Sa-Token）。第一次用某个微信打开时，后端查不到绑定 → 页面展开绑定表单，
填网页端注册的登录名+密码过一次校验即完成绑定，之后免密直登。一个微信只能绑一个成员，一个成员只能绑一个微信（后端 409 防串号）。

## 简报播报

简报页生成/加载出简报后有「朗读简报」：后端把简报清洗成纯文本并分段（`POST /api/voice/tts/plan`），
小程序逐段合成 MP3（`POST /api/voice/tts/segment`）顺序播放，支持暂停/继续/停止，播放当前段时预取下一段。
后端需要环境变量 `SEED_AUDIO_API_KEY`（火山 OpenSpeech seed-audio）；未配时点朗读会收到 503 的明示提示，不会假装播放。

## 订阅消息

晨报/复习提醒走订阅消息：公众平台申请模板 → 模板 ID 同时填 `utils/config.js` 与后端 `WECHAT_TEMPLATE_*` → 页面点订阅授权一次可推一条；
简报页的订阅按钮带管道自检（调 `/api/wechat/notify-test` 立刻发一条测试消息验证全链路）。
